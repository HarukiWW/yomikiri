# Yomikiri RU

Форк [Yomikiri](https://github.com/BlueGreenMagick/yomikiri) (база — релиз v0.3.5) для русскоязычных изучающих японский. Это уже не просто перевод оригинала: словарь, частотные данные, приложение для iOS и видеоплеер переработаны.

Проект состоит из трёх частей:

- **Словарь** — русско-японский словарь на основе Kolobok (Jitendex), собирается из исходников в бинарный формат Yomikiri.
- **Браузерное расширение** — поиск слов и добавление в Anki; для iOS работает в Safari.
- **Приложение для iOS** — словарь, статистика, настройки, видеоплеер с поиском по субтитрам, добавление слов через меню «Поделиться».

## Чем отличается от оригинала

### Словарь

- Встроенный английский словарь заменён на **русский словарь Kolobok**. Конвертер лежит в `custom-dict/` (архив Yomitan → JMdict XML). В карточке слова показываются русские значения и грамматические пометы.
- **Примеры предложений** под значениями: японское предложение с выделенным ключевым словом и русский перевод (до двух на значение). Примеры берутся из того же словаря Yomitan и вписываются в XML при сборке; формат добавлен в Rust-бэкенд и генератор словаря. Примеры есть не у всех слов, а только у тех, у кого они есть в исходном словаре.
- **Английский словарь** доступен как «контрольная сборка»: при запуске workflow параметр `english` оставляет оригинальный словарь. Переключателя в самом приложении нет.
- **Частотность**: данные Jiten (в том числе WebNovel) встроены в приложение при сборке из файлов `custom-dict/*freq*.zip` (формат Yomitan, `term_meta_bank`). Метки словарей с рангами показываются в окне подсказки. Импорта частотных словарей внутри приложения нет.
- **Уровни JLPT** (N5–N1) из списков `custom-dict/jlpt_n*.csv`. Слово сопоставляется по написанию и чтению вместе; запись без чтения используется, только если чтения нет и у слова в тексте.
- **Произношение (pitch accent)**: компактное отображение рядом со словом, данные из Yomitan-словаря `custom-dict/pitch*.zip` (Kanjium).

### Подсветка слов

- Слова в тексте и в субтитрах окрашиваются по уровню JLPT и по частотному рангу (диапазон задаётся в настройках, по умолчанию 3000–8000).
- Слова, уже добавленные в Anki или импортированные из вашей колоды, **не подсвечиваются**.

### Anki

- **Добавление слов** в Anki из окна словаря, из видеоплеера и через меню «Поделиться» (расширение Yomikiri Action) в других приложениях и в Safari. Добавленные слова общие для приложения, расширения и меню «Поделиться» (App Group).
- **Возврат из Anki**: после добавления слова AnkiMobile возвращает в Yomikiri (`yomikiri://ankiReturn`), окно словаря закрывается и видео продолжает играть.
- **Импорт колоды Anki** (`.colpkg` или `.apkg`): Настройки → «Импорт колоды Anki». Из заметок берутся слова (поле Furigana, затем Word, затем первое поле), они попадают в список известных слов и перестают подсвечиваться. Работает на устройстве, без интернета. Поддерживаются новые коллекции Anki (zstd + SQLite).
- Поле Anki типа **audio** и кнопка озвучки в карточке слова: слово читается японским голосом iOS.
- **Перевод предложений** использует механизм оригинала, целевой язык — русский.
- **Добавленные слова**: список в приложении, с возможностью удалить все.

### Интерфейс

- Интерфейс расширения и приложения **на русском**. Переключателя языка нет.
- **Тёмная тема.** Светлой темы в форке нет.
- Кнопки **A− / A+** для размера текста в окне подсказки.
- **Окно словаря**: прозрачность настраивается в настройках плеера («Окна словаря → Прозрачность»).

### Приложение для iOS

- **Вкладки**: «Статистика», «Словарь», «Видео», «Настройки».
- **Статистика**: сколько слов добавлено в Anki, кандзи, счётчик чтения, подробности по дням.
- **Синхронизация** настроек, статистики и добавленных слов с расширением Safari через App Group.

### Видеоплеер (вкладка «Видео»)

Плеер на KSPlayer: MKV декодируется через FFmpeg, MP4 играет системный AVPlayer.

- **Библиотека**: видео в `Documents/Videos` (в «Файлах»: На iPhone → Yomikiri → Videos), папки, добавление кнопкой «+», позиция просмотра запоминается, у просмотренных видео есть пометка.
- **Поиск слов в субтитрах**: нажатие на слово открывает словарь приложения с добавлением в Anki. Слова в строке подсвечиваются по JLPT и частоте. В начале видео в строке состояния показывается, что подсветка видит (включена ли, сколько таблиц, диапазон рангов).
- **Окно словаря**: в портрете системное окно, в альбомной ориентации панель внизу экрана (свободное место с видео остаётся сверху). Затемнения нет (iOS 16.4+). Закрывается нажатием на свободную полосу или смахиванием.
- **Встроенные субтитры**: текстовые дорожки (SRT, ASS/SSA, mov_text, WebVTT) читаются прямо из файла, без декодера. Если реплики пересекаются по времени, показываются все активные.
- **Графические субтитры** (PGS, VobSub): японский текст распознаётся через OCR (Apple Vision, `ja-JP`). Режимы: «Точный (медленнее)», «Быстрый», «Не распознавать». Точность OCR зависит от качества картинки.
- **Внешние субтитры** `.srt`, `.ass`, `.ssa`, `.vtt`: файл с тем же именем рядом с видео подхватывается сам, либо добавляется кнопкой «Добавить свои субтитры».
- **Задержка субтитров** с шагами 0.1 и 0.5 с, запоминается для каждого файла. **Автоподбор задержки** сравнивает тайминги внешнего файла со встроенной дорожкой.
- **Запоминание выбора субтитров**: для каждого видео отдельно; для нового видео подставляется последний выбор (внешний файл с тем же суффиксом, дорожка того же языка или «выкл»). Выбранный внешний файл не сбрасывается автовыбором плеера.
- **Японская аудиодорожка и японские субтитры** выбираются по умолчанию, если системный язык — японский.
- **Стабильность**: после сворачивания приложения плеер сам возобновляет вывод кадра (если картинка зависала при идущем звуке), включён режим 120 Гц для iPhone с ProMotion, отключена асинхронная декомпрессия.

## Ограничения

- **Видеоплеер требует iOS 16 или новее.** Минимальная версия приложения — 15.4. Режим без затемнения окна словаря в портрете работает с iOS 16.4.
- **OCR графических субтитров** может ошибаться и работает медленнее текстовых дорожек.
- **Рывки картинки** на тяжёлых MKV (HEVC 10-bit, высокий битрейт) и при 24 кадрах/с на экранах 60 Гц возможны. На iPhone с ProMotion (120 Гц) заметно ровнее.
- **Импорт колоды Anki** и список известных слов работают в приложении и в плеере. Веб-расширение в Safari использует свой список добавленных слов.
- **Сборка не подписана.** `.ipa` устанавливается через сторонний инструмент подписи (AltStore, Sideloadly, GBox), в App Store приложение не публикуется.
- **Лицензия.** Исходники форка открыты под MIT, как и оригинал. Из-за KSPlayer (GPLv3) сборка для iOS распространяется под GPLv3.

## Сборка

Сборка запускается через GitHub Actions (файл workflow в `.github/workflows/`):

1. Берётся код оригинала на фиксированном релизе, патчи применяются по порядку, затем собирается приложение.
2. Для словарей нужен релиз `dict` в этом репозитории с архивом русского словаря (`jp-ru-*.zip`); исходные файлы JMdict/JMnedict скачиваются автоматически. Частотные словари (`*freq*.zip`), словарь произношения (`pitch*.zip`) и списки JLPT (`jlpt_n*.csv`) лежат в `custom-dict/`.
3. Параметры запуска: `english` (контрольная сборка с английским словарём), имя релиза и файла русского словаря, App Group и общая связка ключей (если установка не проходит, их можно отключить).
4. Результат — неподписанный `Yomikiri-RU-v<версия>.ipa` в артефактах запуска, и лог `xcodebuild-log-v<версия>`.

Версия задаётся в `APP_VERSION` внутри workflow (сейчас 1.21).
