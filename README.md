# Yomikiri RU

Форк [Yomikiri](https://github.com/BlueGreenMagick/yomikiri) (база — релиз v0.3.5) для русскоязычных изучающих японский. Сейчас это уже не просто перевод оригинала: словарь, частотные данные, видеоплеер и приложение для iOS переработаны.

Проект состоит из трёх частей:
- **Словарь** — русско-японский словарь на основе Kolobok, собирается из исходников в бинарный формат Yomikiri.
- **Браузерное расширение** — поиск слов и майнинг в Anki, работает в Chrome, Firefox, Safari.
- **Приложение для iOS** — статистика, словарь, видеоплеер с поиском по субтитрам, общий доступ к файлам с расширением Safari.

## Чем отличается от оригинала

### Словарь
- Встроенный английский словарь заменён на **русский словарь Kolobok** (JMdict-формат, конвертер лежит в `custom-dict/`). Словарь содержит русские определения, грамматические пометы и примеры.
- **Примеры предложений** показываются в карточке слова: японский текст с выделенным ключевым словом и русский перевод. Формат примеров добавлен в Rust-бэкенд и генератор словаря.
- **Английский словарь** сохраняется рядом и доступен переключением в настройках. Если английского файла нет, используется русский.
- **Частотность**: подсветка слов по частотным словарям (Jiten) и по уровням JLPT, метки словарей в окне подсказки.
- **Свои частотные словари**: импорт архивов Yomitan (`term_meta_bank`) прямо в приложении, у каждого словаря своя метка.
- **Произношение (pitch accent)**: компактное отображение рядом со словом, данные из Kanjium.

### Anki и аудио
- Поле Anki типа **audio** и кнопка проигрывания в карточке слова.
- **Перевод предложений** использует механизм из оригинала, но целевой язык — русский.

### Интерфейс и темы
- Полностью **русский интерфейс** в расширении и в приложении. Переключатель языка RU/EN в настройках (веб-страницы переводятся по таблице, для SwiftUI используются `ru.lproj` и `en.lproj`).
- **Тёмная тема по умолчанию**, светлая доступна в настройках.
- В окне подсказки есть кнопки **A− / A+** для размера текста.

### Приложение для iOS (новое)
- **Вкладка «Статистика»**: сколько слов добавлено в Anki, кандидаты по кандзи, счётчик чтения, всплывающие подробности.
- **Общий доступ и синхронизация** с расширением Safari через App Group.
- **Видеоплеер** (вкладка «Видео») на KSPlayer:
  - MKV и MP4 открываются без конвертации. MKV декодируется через FFmpeg, MP4 через системный AVPlayer.
  - **Поиск слов в субтитрах**: тап по слову открывает словарь приложения, а не копирует текст.
  - **Внешние субтитры** `.srt`, `.ass`, `.ssa`, `.vtt`: файл рядом с видео с тем же именем подхватывается сам, либо добавляется кнопкой «Субтитры».
  - **Задержка субтитров** с шагом 0.1 и 0.5 с, значение запоминается для каждого файла.
  - **Автоподбор задержки**: приложение сравнивает тайминги внешнего файла с встроенной дорожкой, которую вы уже посмотрели, и подбирает сдвиг.
  - **Японская аудиодорожка и японские субтитры** выбираются по умолчанию, если системный язык японский.
  - Видео лежат в папке **Documents/Videos**, она видна в приложении «Файлы» (На iPhone → Yomikiri → Videos).

## Ограничения

- **Графические субтитры** (PGS, DVD, DVB) не распознаются: их текст недоступен, поэтому поиск по ним не работает.
- **Видеоплеер требует iOS 16 или новее.** Минимальная версия приложения остаётся 15.4.
- **Производительность** на тяжёлых MKV (HEVC 10-bit, высокий битрейт) не гарантирована: часть файлов может подтормаживать.
- **Сборка не подписана.** `.ipa` устанавливается через сторонний инструмент подписи (например, AltStore или Sideloadly), в App Store приложение не публикуется.
- **Лицензия.** Исходники форка открыты под лицензией MIT, как и оригинал. Из-за KSPlayer (GPLv3) сборка для iOS распространяется под GPLv3.

## Сборка

Сборка запускается через GitHub Actions по файлу `build-ios-v18.yml`:
1. Берёт код оригинала на фиксированном коммите, применяет патчи-шаги по порядку и собирает приложение.
2. Для словарей нужен релиз `dict` в этом репозитории с архивом русского словаря (`jp-ru-*.zip`) и исходными файлами JMdict/JMnedict, которые скачиваются автоматически.
3. Результат — неподписанный `Yomikiri-RU-v<версия>.ipa` в артефактах запуска.

Версия задаётся в `APP_VERSION` внутри workflow.
